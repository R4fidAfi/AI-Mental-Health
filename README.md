# 🧠 MindGuard AI - Student Mental Health Dashboard

**Professional Mental Health Analytics Platform with AI Prediction**

A beautiful, dark-themed, production-grade Streamlit dashboard for analyzing student mental health patterns using advanced data visualization and machine learning.

![Dashboard Preview](assets/preview.png)

## ✨ Features

### Core Capabilities
- **Interactive Multi-Page Dashboard** with epic dark UI
- **Comprehensive Data Explorer** with filtering & export
- **Advanced Visualizations** (Plotly + Seaborn)
- **Machine Learning Model Arena** (5+ algorithms with comparison)
- **Smart Risk Predictor** with comprehensive assessment form
- **AI-Powered Insights** engine
- **Professional Report Export** (PDF + CSV)

### Technical Excellence
- Clean architecture (utils, components, pages)
- Full caching for performance
- Robust error handling
- Professional code quality
- Responsive dark theme with glassmorphism

## 🚀 Quick Start

```bash
# 1. Clone or navigate to project
cd mental-health-dashboard-main

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the dashboard
streamlit run app.py
```

## 📊 Dataset
Uses the "Student Mental Health" dataset containing:
- Demographics (age, gender, course, year, CGPA)
- Mental health indicators (Depression, Anxiety, Panic Attack)
- Treatment seeking behavior
